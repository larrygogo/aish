## 1. 技术方案概览

### 1.1 核心设计原则：单一 SVG 真相来源

```
aish.svg  ──[build.rs (resvg)]──► PNG ×8 ──► [build.rs (icns)]──► ICNS（macOS）
              (Rust build crate)              [gen-icons.js (Bun)]──► ICO（Windows）
                                             ──────────────────────► PNG 套装（Linux）
```

**优势**：
- 所有平台和尺寸均由同一 SVG 源生成，永不漂移
- 修改设计时仅需改 SVG，自动重新生成所有产物
- 无需平台特定的工具（如 macOS iconutil、ImageMagick 等）

### 1.2 工具链选择

| 步骤 | 工具 | 选择原因 |
|------|------|---------|
| SVG → PNG | `@resvg/resvg-js` (Bun script) + `resvg` (Rust) | 跨平台、完整 SVG 1.1 支持、无依赖 |
| PNG → ICO (Windows) | `png-to-ico` (npm) | 纯 JS、无需 Windows toolchain |
| PNG → ICNS (macOS) | `@fiahfy/icns` (npm) + `icns` (Rust crate) | 纯 JS 和 Rust、无需 macOS iconutil |
| Windows 资源嵌入 | `winresource` (Rust crate) | 标准 Rust build crate，编译期集成 |
| macOS Bundle | `cargo-bundle` metadata + Info.plist | GPUI/cargo 原生支持 |
| Linux 桌面 | `.desktop` 文件标准 | FreeDesktop.org 规范 |

## 2. 实现步骤（7 个 Task）

### Task 1：创建 SVG 主设计源
**关键文件**：`assets/icons/aish.svg`  
**输入**：设计规格（见 Spec 2.2-2.4）  
**产出**：64×64 SVG，包含 `>_` 符号、CRT 磨光、扫描线  
**验收标准**：
- [ ] 文件存在，格式有效（XML well-formed）
- [ ] viewBox 正确设置为 `0 0 64 64`
- [ ] 包含 `<filter id="bloom">` 和 `<pattern id="scanlines">`
- [ ] `>` 和 `_` 符号使用 `#00FF41` 颜色
- [ ] 背景为 `#000000` 圆角矩形 (`rx="10" ry="10"`)

**依赖**：无  
**时间**：< 1 小时（纯设计）

---

### Task 2：创建 Bun 生成脚本
**关键文件**：`scripts/gen-icons.js`  
**输入**：`assets/icons/aish.svg`  
**产出**：
- `assets/icons/aish-{16,32,48,64,128,256,512,1024}.png`
- `assets/aish.ico`
- `assets/aish.icns`

**脚本功能**：
1. 读取 SVG
2. 用 `@resvg/resvg-js` 渲染 8 个 PNG 尺寸
3. 用 `png-to-ico` 从 6 个尺寸（16/32/48/64/128/256）生成 ICO
4. 用 `@fiahfy/icns` 从 7 个尺寸（16/32/64/128/256/512/1024）生成 ICNS
5. 输出日志 `✅ PNG 16×16 → ...`

**验收标准**：
- [ ] 脚本可用 `bun run scripts/gen-icons.js` 执行
- [ ] 8 个 PNG 都生成在 `assets/icons/`
- [ ] ICO 和 ICNS 生成在 `assets/`（repo 根）
- [ ] 无 unhandled error（catch 错误并 exit 1）

**依赖**：Task 1  
**时间**：< 2 小时

---

### Task 3：运行脚本生成所有产物
**前置**：Task 1 + Task 2 完成  
**命令**：`bun run scripts/gen-icons.js`  
**产出**：
- 8 × PNG + ICO + ICNS，共 11 个文件

**验收标准**：
- [ ] 所有文件存在，文件大小 > 0
- [ ] PNG 文件头为 `89 50 4E 47`（PNG magic）
- [ ] ICO 文件头为 `00 00 01 00`（ICO magic）
- [ ] ICNS 文件头为 `69 63 6e 73`（ASCII "icns"）
- [ ] 脚本输出无错误

**依赖**：Task 1, Task 2  
**时间**：< 5 min（自动）

---

### Task 4：Windows build.rs 集成
**关键文件**：`crates/aish-app/build.rs`  
**目标**：编译期自动生成 PNG/ICO，EXE 资源嵌入 ICO  

**build.rs 应实现**：
1. 在 `$OUT_DIR/icons/` 中生成 8 个 PNG（16/32/48/64/128/256/512/1024）
2. 从 PNG 生成 `aish.ico`（包含 16/32/48/64/128/256 六个尺寸）
3. Windows 平台：用 `winresource::WindowsResource` 嵌入 ICO 到 EXE
4. 设置 ProductName / FileDescription / LegalCopyright

**build 依赖**（Cargo.toml）：
```toml
[build-dependencies]
resvg = "0.47"
icns  = "0.4"
ico   = "0.5"

[target.'cfg(windows)'.build-dependencies]
winresource = "0.1"
```

**验收标准**：
- [ ] build.rs 指向正确的 SVG 源：`../../assets/icons/aish.svg`
- [ ] 生成 PNG 命名为 `aish-{size}.png`（与 Bun 脚本一致）
- [ ] 包含 48px（ICO 标准）
- [ ] 编译无错误：`cargo build --release`
- [ ] Windows 上：EXE 成功嵌入 ICO，资源管理器显示图标

**依赖**：Task 1, Task 2, Task 3  
**时间**：< 2 小时

---

### Task 5：macOS Bundle 配置
**关键文件**：
- `crates/aish-app/Cargo.toml`（bundle metadata）
- `packaging/macos/Info.plist`

**Cargo.toml 配置**：
```toml
[package.metadata.bundle]
name              = "aish"
identifier        = "com.larrygogo.aish"
version           = "0.1.0"
copyright         = "Copyright © 2026 larry. MIT License."
category          = "Developer Tool"
short_description = "AI-powered SSH client"
icon              = ["assets/icons/aish.svg"]
```

**Info.plist 配置**：
```xml
<key>CFBundleIconFile</key>
<string>aish</string>  <!-- 会在 Contents/Resources/ 中查找 aish.icns -->
<key>CFBundleIconName</key>
<string>aish</string>
```

**验收标准**：
- [ ] Cargo.toml `icon` 指向 `assets/icons/aish.svg`
- [ ] Info.plist 中 `CFBundleIconFile` 设置为 `aish`
- [ ] macOS 打包时，ICNS 被放入 `aish.app/Contents/Resources/aish.icns`
- [ ] 在 macOS Dock 拖入应用后，图标正确显示

**依赖**：Task 3  
**时间**：< 1 小时

### Task 6：Linux 桌面集成
**关键文件**：`packaging/linux/aish.desktop`  

**Desktop 文件内容**：
```
[Desktop Entry]
Version=1.0
Type=Application
Name=aish
Comment=AI Shell - SSH Terminal with AI
Exec=aish
Icon=aish              # 系统会在 icon theme 中查找 aish.png
Terminal=false
Categories=System;TerminalEmulator;Network;
Keywords=ssh;terminal;ai;shell;
StartupWMClass=aish
```

**安装 icon 到系统**（可选，用户手动或通过 .deb）：
- 复制 `assets/icons/aish-{48,64,128,256}.png` 到 `/usr/share/icons/hicolor/{size}x{size}/apps/aish.png`

**验收标准**：
- [ ] `.desktop` 文件存在，格式有效（Desktop Entry spec）
- [ ] Icon 键值为 `aish`
- [ ] StartupWMClass 为 `aish`（与 GPUI 应用窗口类名一致）
- [ ] Linux 文件管理器正确显示图标

**依赖**：Task 3  
**时间**：< 30 min

## 3. 质量门禁（每 Task 完成后）

```bash

# 无警告检查

# 单元测试
cargo test --workspace
```

**预期结果**：
- ✅ fmt 无输出（已格式化）
- ✅ clippy 无 warning（零容忍）
- ✅ test 全过（包括 106 个现有测试 + 0 个新增）

**失败处理**：
- fmt 失败：不可能，但若有应用修复
- clippy 失败：修复代码，重新运行
- test 失败：定位并修复，重新运行

## 7. 风险与缓解

| 风险 | 概率 | 影响 | 缓解 |
|------|------|------|------|
| resvg 版本兼容性 | 低 | 编译失败 | 使用已验证的 0.47；需要时升级 |
| 跨平台工具缺失 | 中 | Windows 无法生成 ICO | 提前在各平台验证 npm 包 |
| 小尺寸像素不清晰 | 中 | 用户无法识别符号 | 逐级查看，手工调整 SVG 坐标 |
| macOS ICNS 生成错误 | 低 | 图标显示为默认 | 测试 @fiahfy/icns，备选使用 resvg + magick |
