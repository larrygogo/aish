> **里程碑代号**：M35.2（M35 视觉迭代的根因修复，与 M35.1 并列 follow-up）

> **关联**：home.rs:739 `⌧` (U+2327) tofu 方块 — 暴露 aish 字体调用从无 fallback chain 的设计漏洞
> **执行顺序**：建议 **先于 M35.1** 实施（根因 > 表象）

## 1. Context

### 1.1 暴露的设计漏洞

home.rs:739 `format!("⌧ tmux:{}", t)` 用了 U+2327（Miscellaneous Technical 区的"X in
Rectangle Box"）。即使该 chunk 走 `TypeRole::Code` 自动 apply JetBrainsMono Nerd Font，
**Nerd Font 也不包含此 glyph**（Nerd Font 增强主要在 PUA 区 U+E000-U+F8FF，不覆盖
Miscellaneous Technical 区） → 渲染为方块 tofu。

调研发现根因不是这一行：

| 调用点 | 写法 | fallback 配置 |
|---|---|---|
| `aish-ui/src/theme/typography.rs:173` | `.font_family(CODE_FONT_NAME)` | ❌ 无 |
| `aish-app/src/terminal/font.rs:34` | `font(FONT_NAME)` | ❌ 无（默认 `fallbacks: None`） |
| `aish-app/src/views/home.rs:790` | `.font_family("JetBrains Mono")` | ❌ 无；**且字体名错** — 非 Nerd Font 版本，缺图标 glyph |

→ **aish 所有字体调用都没挂 fallback chain**。任何主字体不带的字符都会 tofu。

### 1.2 GPUI 原生支持 fallback

调研 zed rev aa16a3b（项目 pin 的版本）确认：

- `gpui::FontFallbacks::from_fonts(Vec<String>)` 创建 fallback 链
- `gpui::Font { fallbacks: Option<FontFallbacks>, ... }` 字段
- `div().font(font)` 会带上 fallback；`div().font_family(name)` **只设 family、不挂 fallback**
- 平台找不到的字体名会自动跳过（不需要 cfg!(target_os)）

### 1.3 范围

**做**：抽 font helper 模块 + 给所有字体调用挂跨平台 symbol fallback 链

**不做**：
- 不 bundle 新字体（0 包大小开销）
- 不引入 emoji fallback（aish 是 SSH 客户端，emoji 不是核心场景）
- 不动 GPUI 内部字体解析逻辑

## 2. 设计决策

### D1 — Fallback 链组成

链顺序（找到一个就停）：

```rust
const FONT_FALLBACK_CHAIN: &[&str] = &[
    "Symbols Nerd Font",      // 图标符号专用（Linux/macOS Homebrew 常装）
    "Segoe UI Symbol",        // Windows 内置 — 含 Miscellaneous Technical 整段
    "Apple Symbols",          // macOS 内置 — 同上
    "Noto Sans Symbols 2",    // Linux 多数发行版预装 / Google Noto
    "Noto Sans CJK SC",       // CJK 罕用字兜底
];
```

**为什么这个顺序**：
1. Symbols Nerd Font 优先 — 已有用户装过 Nerd Font 套件，符号最全
2. Segoe UI Symbol / Apple Symbols — 操作系统内置，零配置可用
3. Noto Sans Symbols 2 — Linux 兜底
4. CJK 放最后 — 仅罕用 CJK 字符需要

**为什么不 bundle Symbols Nerd Font**：
- 已 bundle JetBrainsMono Nerd Font (~5MB)，Nerd Font glyph 全在
- U+2327 这类标准 Unicode 字符需要系统 symbol 字体兜底（即使 bundle Symbols Nerd Font 也未必有）
- 多 bundle 1MB 收益 < 维护成本

**alt 对比**：
- A. ❌ bundle Symbols Nerd Font：+1MB，但对 U+2327 不一定覆盖
- B. ❌ bundle Noto Sans Symbols 2：+2MB，全覆盖但包大太
- C. ✅ 系统 symbol font fallback chain：0 开销，覆盖 ≥95% tofu 场景

### D2 — Helper 模块设计

新建 `crates/aish-ui/src/font.rs`：

```rust
//! Font fallback chain — 跨平台 symbol/CJK 兜底，防 tofu。

use gpui::{font, Font, FontFallbacks, SharedString};
use std::sync::Arc;
use std::sync::OnceLock;

const FONT_FALLBACK_CHAIN: &[&str] = &[
    "Symbols Nerd Font",
    "Segoe UI Symbol",
    "Apple Symbols",
    "Noto Sans Symbols 2",
    "Noto Sans CJK SC",
];

static FALLBACKS: OnceLock<FontFallbacks> = OnceLock::new();

fn fallbacks() -> FontFallbacks {
    FALLBACKS
        .get_or_init(|| {
            FontFallbacks::from_fonts(
                FONT_FALLBACK_CHAIN.iter().map(|s| s.to_string()).collect(),
            )
        })
        .clone()
}

/// Code font (mono Nerd Font) + symbol fallback chain.
pub fn code_font() -> Font {
    let mut f = font(crate::theme::typography::CODE_FONT_NAME);
    f.fallbacks = Some(fallbacks());
    f
}

/// Sans font (system default) + symbol fallback chain.
pub fn sans_font() -> Font {
    let mut f = font(".SystemUIFont"); // GPUI 平台默认 UI 字体
    f.fallbacks = Some(fallbacks());
    f
}
```

**为什么 OnceLock**：FontFallbacks 内部是 Arc，构造一次即可全程克隆；OnceLock 是 std
1.70+ 的标准做法，比 `lazy_static!` 干净。

**为什么 `.SystemUIFont`**：GPUI 内置 special name，自动展开为 Windows Segoe UI / macOS
SF Pro / Linux 系统 sans —— 比 hardcode "JetBrains Mono" 更对（home.rs:790 当前错误）。

### D3 — Apply 路径改造

| 调用点 | 改前 | 改后 |
|---|---|---|
| typography.rs:170-173 Code role | `s.font_family(CODE_FONT_NAME)` | `s.font(aish_ui::code_font())` ※ 注意：TextStyleRefinement 需要类似 chain 写法，T2 实施时确认 GPUI API |
| home.rs:790 | `.font_family("JetBrains Mono")` | `.font(aish_ui::sans_font())` |
| terminal/font.rs:34 | `font(FONT_NAME)` | `aish_ui::code_font()`（或保留独立 fn 但内部用 fallback chain） |

**注意**：typography.rs 处当前是修改 `TextStyleRefinement`，不是 element styled，API 不同。
T2 时具体确认 — 可能需要分别设 `font_family` + `font_fallbacks` 两个字段（参考
gpui style.rs:406 `pub font_fallbacks: Option<FontFallbacks>`）。

## 4. Tasks（按依赖顺序）

### T0 — GPUI Font API + TextStyleRefinement 字段确认（30 分钟）

**目的**：确认 typography.rs 改造路径
**做**：
- 读 `~/.cargo/git/checkouts/zed-*/aa16a3b/crates/gpui/src/style.rs:406` 看
  `TextStyleRefinement.font_fallbacks` 字段
- 验证：在 typography.rs apply 路径里能否同时设 `font_family + font_fallbacks` 两字段
- 输出：在本 plan T2 标注 typography apply 写法（要么直接两字段，要么用 helper Font）

**质量门禁**：无（调研）

**结论（2026-05-17 完成）**：

- `Styled::font_family(name)` (styled.rs:685) **只设 family，不动 fallback** → aish 走这条所以 fallback 永远 None。
- `Styled::font(Font)` (styled.rs:697) 把 Font 5 字段（family/features/weight/style/fallbacks）**全部覆盖**到 TextStyleRefinement —— 是唯一公开同时设 family + fallbacks 的方式。
- `Styled::text_style()` 返回 `&mut TextStyleRefinement` (styled.rs:483)，可直接 inline mutate `font_fallbacks` 字段（不破坏其他），但要 `let mut e = ...; e.text_style().font_fallbacks = ...; e` 三句不链式。
- TextStyleRefinement 由 `Refineable` derive 宏生成（style.rs:393）。
- TextRun（最终渲染单元）的 font 带 fallbacks (style.rs:519-525)，所以 fallback 全程贯通到渲染层。

**T2 实施路径决策**：走 `.font(Font)` 路径。helper 返回**基础 Font**（family + fallbacks，weight/style 默认）；typography.rs apply 时**自己设 `font.weight = style.weight`** 再 `.font(font)` 整套压入 —— 一次 mutation 同时挂 family + fallbacks + weight，保持链式。

```rust
// typography.rs T2 改造后写法（草稿）
if role == TypeRole::Code {
    let mut code = aish_ui::font::code_font();  // family + fallbacks
    code.weight = style.weight;                  // 同步当前 role weight
    s = s.font(code);                            // 一次性 apply 5 字段
} else {
    s = s.font_weight(style.weight);             // 非 Code role 走原路径
}
```

## 5. Self-Review

### 5.1 风险

| 风险 | 等级 | 缓解 |
|---|---|---|
| Segoe UI Symbol / Apple Symbols / Noto Sans Symbols 2 都不含 U+2327 | 低 | U+2327 是 ISO 9995-7 标准符号，3 个系统字体均有；T5 视觉验证 |
| GPUI fallback chain 在某平台不工作（zed Linux issue #17254） | 中 | 风险只在 Linux；Windows 主要平台，aish 用户多 Windows，T5 验证 |
| fallback chain 顺序导致 CJK 字符走错字体（如把日文走简中字体） | 低 | CJK 放最后，主路径不会触发；遇到再调 |
| typography.rs:170-173 改造破坏现有 200+ 测试 | 中 | T2 完成后立即跑全量测试，clippy 通过才 commit |
| `.SystemUIFont` 在 GPUI Linux 解析失败 | 低 | M35 T17 加 light theme 时已验证 GPUI Linux 起得来；fallback chain 会兜 |
